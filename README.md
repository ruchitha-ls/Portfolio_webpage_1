# 🌟 Ruchitha's Personal Portfolio Website

A clean, responsive, and modern personal portfolio website built using standard web technologies. This site showcases my work and experience in Full Stack Development, IoT and Cybersecurity.

## ✨ Key Features

* **Responsive Design:** Ensures a seamless experience across all devices (desktops, tablets, and phones).
* **Clean, Semantic HTML:** Well-structured and accessible HTML5 markup.
* **Modern CSS:** Custom styling, advanced layouts (Flexbox/Grid), and polished visual effects.
* **Smooth scrolling navigation, Interactive project cards**

## 🛠️ Technologies Used

| Technology | Purpose |
| :--- | :--- |
| **HTML5** | Core structure and semantic markup. |
| **CSS3** | Custom styling and responsive breakpoints. |

## 🚀 Getting Started (How to View)

There are two primary ways to view this portfolio:

### Option 1: Live Demo (Recommended)

The live version of the site is hosted at:
➡️ **https://ruchitha-ls.github.io/Portfolio_webpage_1/** ⬅️

### Option 2: Run Locally

To get a local copy up and running, follow these simple steps.

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/ruchitha-ls/Portfolio_webpage_1/
    cd Portfolio_webpage_1
    ```
2.  **Open the Index File:**
    Simply open the primary file (`index.html`) in your preferred web browser (e.g., Chrome, Firefox).
